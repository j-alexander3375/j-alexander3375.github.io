Frequently Asked Questions

How do I report a security vulnerability?

Please do not open a public issue for security vulnerabilities. Instead, email help@lotus-lang.org with details. We take security seriously and will respond promptly.

What's the best way to ask for help?

If you're stuck on something, email help@lotus-lang.org with:

  • What you're trying to do
  • What you've already tried
  • Your code or error message
  • Your environment details

How can I contribute to Lotus?

Great question! Check out the Development Guide for detailed instructions on setting up your environment and making contributions.

Where can I learn more about Lotus?

Start with the Getting Started guide, then explore the full documentation and code examples.

How do I report a documentation issue?

Found a typo or confusing documentation? Either:

  • Open an issue on GitHub
  • Email help@lotus-lang.org with the details

What should I include in a bug report?

Good bug reports include:

  • A clear title describing the issue
  • Steps to reproduce the problem
  • Expected vs actual behavior
  • Lotus version and environment info
  • Minimal code example that demonstrates the bug

How long does it take to get a response?

We aim to respond to emails within 24-48 hours. GitHub issues may be handled by community members. Priority is given to security issues and critical bugs.

Code of Conduct

The Lotus community is dedicated to providing a welcoming and inclusive environment. We expect all community members to be respectful and constructive in all interactions.

  • Be respectful and inclusive
  • Avoid aggressive or dismissive language
  • Focus on the idea, not the person
  • Help others learn and grow
  • Report violations to help@lotus-lang.org

# j-alexander3375.github.io

Personal portfolio for Joshua Alexander, served by GitHub Pages at
https://j-alexander3375.github.io/.

Plain HTML and CSS with no build step: edit `index.html` and push.

| File | Purpose |
| --- | --- |
| `index.html` | The portfolio page |
| `404.html` | Shown for any missing page |
| `resume.pdf` | Résumé linked from the contact section |
| `robots.txt` | Crawler rules, pointing to both sitemaps |
| `sitemap.xml` | Sitemap for this site |
| `.nojekyll` | Tells Pages to serve files as-is, without Jekyll |

Preview locally with `python -m http.server` and open http://localhost:8000.
